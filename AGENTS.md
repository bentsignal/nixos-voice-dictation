# Repository and upstream policy

- This project is maintained only in `bentsignal/voice-dictation`.
- Treat the originating project and every other repository or fork as
  read-only by default.
- Do not push changes, open or update pull requests, open or comment on issues,
  publish releases, or perform any other write against another repository
  unless a human explicitly instructs you to do so.
- Never infer permission to upstream work from a request to implement, commit,
  push, or publish changes in this repository. Upstream interaction requires a
  separate, explicit human instruction.
